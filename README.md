## Project Overview
This project analyzes Superstore retail sales data using Python, Pandas, Matplotlib, and SQLite.
The objective is to identify sales trends, top-performing categories, customer segments, and seasonal patterns.

## Tools Used
- Python (Pandas, Matplotlib)
- SQLite
- Jupyter Notebook

## Key Insights
- Technology category generates the highest sales
- Consumer segment contributes the most revenue
- Sales peak during November–December
